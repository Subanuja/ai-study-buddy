# 💜 AI Study Buddy

Your personal space to learn, practise, and improve.

AI Study Buddy is an AI-powered learning application designed to help students understand topics, generate study notes, practise quiz questions, and interact with an AI study assistant.

## ✨ Features

* 📚 **Explain a Topic** — Get explanations of study topics.
* 📝 **Generate Study Notes** — Create notes for revision.
* 🧠 **Generate Quiz Questions** — Practise with AI-generated questions.
* 💬 **AI Study Chat** — Ask questions and learn interactively.
* 🏠 **Dashboard** — Access the main study features.
* ℹ️ **About Project** — Learn about the application.

## 🛠️ Technologies Used

* Python
* Streamlit
* Backboard SDK
* python-dotenv

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd ai-study-buddy
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

### 3. Activate the Virtual Environment

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

Install the packages required by the project using your project's dependency file.

### 5. Configure Your API Key

Create a `.env` file in the project folder and add your Backboard API key:

```env
BACKBOARD_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your own API key.

**Important:** Never upload your `.env` file or expose your API key on GitHub.

### 6. Run the Application

```bash
streamlit run app.py
```
